# BRVM Éclair — Plan éditorial & horaires (v2, 17/11/2026)

## Principe
Page de référence sur la Bourse de l'UEMOA : données réelles, actualité, pédagogie, fiches, acteurs. Le flash news est UN format parmi douze. Jamais de résumé quotidien de séance (revue hebdo du vendredi uniquement).

## 12 rubriques (rotation)
1. CHIFFRE CLÉ : capitalisation, valeur/volumes échangés, nombre de sociétés, encours UMOA-Titres (source BRVM/UMOA-Titres)
2. FICHE SOCIÉTÉ : identité, secteur, activité, dividende, poids (une société cotée par fiche)
3. FOCUS ACTION : ce qui fait bouger une action (résultats, dividendes, communiqués) — information, jamais conseil
4. INDICES : Composite, BRVM 30, Prestige, indices sectoriels — comment ça se calcule, ce qu'ils disent
5. LES ACTEURS : BRVM, DC/BR, SGI, AMF-UMOA, BCEAO, UMOA-Titres, teneurs de compte — qui fait quoi
6. FLASH NEWS : vraie actu chaude (communiqués, BCEAO, UMOA-Titres, nouveautés)
7. UMOA-TITRES : adjudications, bons vs obligations, rendements
8. COMMENT ÇA MARCHE : journée de cotation, ordre de bourse, fixing, seuils de variation, règlement-livraison
9. CE QUI FAIT VARIER LE COURS : offre/demande, résultats, dividendes, liquidité, actualité
10. MYTHE OU RÉALITÉ / VRAI-FAUX / QUIZ : engagement
11. MOT DU JOUR : dividende, coupon, PER, capitalisation, liquidité…
12. REVUE HEBDO (vendredi) : variation, plus fortes hausses/baisses, capitalisation, volumes, secteurs, fait marquant

## Rythme (heure d'Abidjan = UTC)
TikTok : 2 vidéos/jour lun–sam (créneaux testés : 06:45 matin trajet ; 20:30 soirée) + Stories ; pas de dimanche.
Facebook : max 2 posts/semaine = FOCUS/FICHE mercredi 07:00 + REVUE vendredi soir après BOC.
Raisonnement : l'étude Buffer (7 M de posts) place les pics TikTok tôt le matin (≈6 h) et le soir (18–23 h) ; les après-midi sont les plus faibles → on quitte le créneau de midi. Les chiffres sont globaux, pas propres à l'UEMOA : on A/B-teste 06:45 / 12:45 / 20:30 pendant 2 semaines et on garde les créneaux gagnants d'après les vues réelles (relevé chaque lundi).

## Semaine type
Lun : 06:45 Chiffre clé / 20:30 Comment ça marche
Mar : 06:45 Flash news (si actu) sinon Fiche société / 20:30 Mythe-réalité
Mer : 06:45 Focus action / 20:30 Acteurs du marché ; FB 07:00 Focus/Fiche
Jeu : 06:45 Indices (sectoriels) / 20:30 UMOA-Titres
Ven : 06:45 Mot du jour / 21:00 Revue hebdo (après BOC) ; FB revue
Sam : 09:00 Quiz / 17:00 Cette semaine à retenir (teaser revue)
Dim : rien

## Règles
2 sources lues par fait ; mention légale ; pas d'IRVM/employeur ; Sonatel fractionnée 10 pour 1 ; voix d'homme (Remy) ; vidéos 25-35 s ; thèmes variés.
